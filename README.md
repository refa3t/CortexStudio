# Cortex Studio Portfolio

Official company portfolio built with standard Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The project is platform-independent and can be deployed to Vercel, Netlify, a Node.js server, or any service that supports Next.js.
